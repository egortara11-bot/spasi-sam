# 🚑 Первая помощь (Школьный проект)

Интерактивный справочник первой помощи с встроенным ИИ-ассистентом на базе **GigaChat API**.

### Возможности
- Быстрый доступ к инструкциям по частым неотложным ситуациям (Минздрав РФ / МЧС).
- Поиск по ключевым словам.
- ИИ-помощник для нестандартных ситуаций с поддержкой непрерывного диалога.
